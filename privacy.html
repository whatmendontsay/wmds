Privacy Policy

WMDS Publisher · Effective 17 November 2026

WMDS Publisher ("the tool") is a private, internal application operated by the owner of the YouTube channel What Men Don't Say ("we", "us"). It is used only by the channel owner to upload videos to, and read statistics for, that channel. It is not available to the public and has no other users.

YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Information we access

With the channel owner's permission (granted through Google's OAuth sign-in), the tool accesses:

  • Upload access to the owner's YouTube channel, to upload videos, set thumbnails and add captions.
  • Read-only YouTube Analytics data for the owner's own videos, such as views, watch time, audience retention and click-through rate.
  • Basic channel information needed to identify the owner's channel.

The tool does not access, collect or store data about viewers, subscribers, commenters or any other YouTube user.

How we use it

This information is used only to publish the owner's videos and to understand how those videos perform, so future videos can be improved. It is not used for advertising, profiling or any other purpose.

Storage and security

The OAuth access token and the analytics figures are stored only on the owner's own computer. They are not uploaded to any server we operate. Access to that computer is restricted to the owner. Statistics are kept for as long as they are useful for improving the channel and are deleted when no longer needed, and in any case within 30 days of access being revoked.

Sharing

We do not sell, rent, share or disclose any information obtained through YouTube API Services to any third party.

Cookies

The tool has no public website functionality and does not use cookies or similar technologies on its users' devices. These information pages set no cookies.

Revoking access

Access can be revoked at any time on the Google security settings page. Once access is revoked, the tool can no longer access the channel, and stored data is deleted as described above.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
